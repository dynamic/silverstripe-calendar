# Security Policy

## Supported Versions

Security fixes are made for the current major release only. Older major versions do not receive security fixes.

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |
| < 3.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities in one of these two ways:

- Email dev@dynamicagency.com, or
- Use GitHub private vulnerability reporting on this repository. Open the Security tab and choose "Report a vulnerability".

Do not open a public GitHub issue for a security report.

When you report a vulnerability, please include:

- The affected version or commit.
- The steps to reproduce the problem.
- The impact you believe the issue has.

## What to Expect

We will acknowledge your report, then investigate and prepare a fix. Once a fix is available, we will release it and coordinate public disclosure with you.
